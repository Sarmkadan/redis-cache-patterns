# RedisCacheServiceJsonExtensions

> **Status: source removed.** `Services/RedisCacheServiceJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `RedisCacheServiceJsonExtensions` class is a static collection of extension methods that convert a `RedisCacheService` to and from JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Services` namespace. Serialization uses web defaults with camelCase names. The methods do not change the `RedisCacheService` instance they are called on.

The methods are not useful in practice. `RedisCacheService` has no public properties, so every instance serializes to `{}`. Its only constructor takes an `IRedisConnection` and a logger, and neither is written to the JSON. Deserialization cannot succeed for any JSON object, because System.Text.Json cannot bind the constructor parameters to properties (see the notes below). The Redis connection, the logger, and the policy and lock state are never part of the JSON.

## API

### ToJson

```csharp
public static string ToJson(this RedisCacheService value, bool indented = false)
```

Serializes a `RedisCacheService` to a JSON string.

- **value**: The cache service instance to serialize.
- **indented**: `true` to format the JSON with indentation; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the service. Always `{}`, with or without indentation.
- **Throws**: `ArgumentNullException` when `value` is null.

When `indented` is `true`, the method creates a copy of the shared options with `WriteIndented` set. For an empty object the copy makes no visible difference.

### FromJson

```csharp
public static RedisCacheService? FromJson(string json)
```

Deserializes a JSON string to a `RedisCacheService`.

- **json**: The JSON string to deserialize.
- **Returns**: `null` when `json` is empty, only whitespace, or the literal `null`. Otherwise the result of deserialization.
- **Throws**: `ArgumentNullException` when `json` is null. `InvalidOperationException` for any JSON object, including `{}` and malformed input such as `{bad`.

The XML documentation says that `FromJson` throws `ArgumentException` for empty or whitespace input and `JsonException` for invalid JSON. The code does not do either. See the notes below.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out RedisCacheService? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized instance when the method returns `true`. Set to `null` in every other case.
- **Returns**: `true` if the JSON was read without a `JsonException`; otherwise, `false`.
- **Throws**: `ArgumentNullException` when `json` is null. `InvalidOperationException` for any JSON object, including `{}` and `{bad`. See the notes below.

Empty and whitespace-only input return `false` without throwing. The literal `null` returns `true` with `value` set to `null`. Any JSON object throws `InvalidOperationException`, because the `JsonException` catch does not match it. `TryFromJson` therefore does not act as a "try" method for object input.

## Serialized format

Every `RedisCacheService` serializes to:

```json
{}
```

- The class exposes no public properties, so no field is written. The Redis connection, logger, policy dictionaries, and statistics aggregator are private, so they are not written either.
- The `indented` form is also `{}`.

## Usage

### Serializing a service instance

```csharp
using RedisCachePatterns.Services;

RedisCacheService service = serviceProvider.GetRequiredService<RedisCacheService>();

string json = service.ToJson();                 // "{}"
string pretty = service.ToJson(indented: true); // "{}"
```

### Handling input that is not a JSON object

```csharp
using RedisCachePatterns.Services;

if (string.IsNullOrWhiteSpace(stored))
{
    return;
}

// Do not rely on TryFromJson for object input: it throws InvalidOperationException, not returns false.
RedisCacheService? restored = RedisCacheServiceJsonExtensions.FromJson(stored);
```

Do not use these methods to persist or restore service state. Any object that is not the literal `null` fails to deserialize, and the serialized form carries no state.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **Deserialization of any JSON object fails:** `RedisCacheService` has a public constructor with parameters and no public properties or parameterless constructor. System.Text.Json therefore throws `InvalidOperationException` ("Each parameter in the deserialization constructor ... must bind to an object property or field") for `{}` and for any other object. The exception is raised before the JSON is read, so malformed input such as `{bad` gives the same exception. This was confirmed by running a probe with a stub class of the same shape. The real class was not compiled for the probe.
*   **`TryFromJson` does not catch `InvalidOperationException`:** Because the `JsonException` catch does not match, object input escapes as an exception even though the method is named `TryFromJson`. Callers that rely on `false` for bad input will get an exception instead.
*   **`TryFromJson` throws `ArgumentNullException` for null:** This matches its XML documentation. `FromJson` does the same.
*   **The XML documentation does not match the code:** `FromJson` documents an `ArgumentException` for empty or whitespace input and `JsonException` for invalid JSON. The code returns `null` for empty or whitespace input and throws `InvalidOperationException` for invalid JSON.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON, so the method returns `true` and sets `value` to `null`. Check `value` before using it.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
*   **Only `RedisCacheService` is covered:** The class has one set of methods for `RedisCacheService`. It does not handle `ICacheService` or other cache types, and it does not handle lists of services.
