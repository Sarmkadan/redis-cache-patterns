# ServiceCollectionExtensionsJsonExtensions

> **Status: source removed.** `Extensions/ServiceCollectionExtensionsJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `ServiceCollectionExtensionsJsonExtensions` class is a static collection of extension methods that convert objects to and from JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Extensions` namespace. Serialization uses web defaults with camelCase property names. The methods do not change the object they are called on.

The only type that `FromJson` and `TryFromJson` can read is the nested `ServiceCollectionPatterns` class. Despite its name, the class has nothing to do with dependency injection registration. See the notes below.

## API

### ToJson

```csharp
public static string ToJson(this object? value, bool indented = false)
```

Serializes an object to a JSON string. The runtime type of `value` decides which properties are written. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **value**: The object to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the object.
- **Throws**: `ArgumentNullException` when `value` is null.

Because the receiver is `object?`, the method is visible on every value in the namespace.

### FromJson

```csharp
public static ServiceCollectionPatterns? FromJson(string json)
```

Deserializes a JSON string to a `ServiceCollectionPatterns`. Property names are matched without regard to case.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized instance. `null` if `json` is empty or only whitespace, or if `json` is the literal `null`.
- **Throws**: `ArgumentNullException` when `json` is null. `JsonException` when the JSON is malformed or cannot be converted to a `ServiceCollectionPatterns`.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out ServiceCollectionPatterns? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized instance when the method returns `true`. Set to `null` in every other case.
- **Returns**: `true` if the JSON was read without a `JsonException`; otherwise, `false`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is an empty string.

Whitespace-only input returns `false`. The literal `null` returns `true` with `value` set to `null`. The XML documentation says that both null and empty input throw `ArgumentNullException`. The code throws `ArgumentNullException` only for null. An empty string throws `ArgumentException`. See the notes below.

## ServiceCollectionPatterns

```csharp
public sealed class ServiceCollectionPatterns
```

A plain container of four `bool` flags. Each property has a public getter and setter and defaults to `false`.

| Property | Description (from XML docs) |
|---|---|
| `AuditingEnabled` | Whether auditing is enabled. |
| `BatchProcessingConfigured` | Whether batch processing is configured. |
| `IdempotencyEnabled` | Whether idempotency is enabled. |
| `PerformanceMonitoringEnabled` | Whether performance monitoring is enabled. |

The class does not register services or change any configuration. Setting a flag only changes the value stored on the instance.

## Serialized format

An instance with `AuditingEnabled = true` and `IdempotencyEnabled = true` serializes to:

```json
{"auditingEnabled":true,"batchProcessingConfigured":false,"idempotencyEnabled":true,"performanceMonitoringEnabled":false}
```

- Every property is always written, including `false` values.
- Property names are camelCase.

## Usage

### Serializing the flags

```csharp
using RedisCachePatterns.Extensions;

var patterns = new ServiceCollectionExtensionsJsonExtensions.ServiceCollectionPatterns
{
    AuditingEnabled = true,
    IdempotencyEnabled = true
};

string json = patterns.ToJson();               // compact
string pretty = patterns.ToJson(indented: true);
```

### Reading the flags and handling bad input

```csharp
using RedisCachePatterns.Extensions;

if (!ServiceCollectionExtensionsJsonExtensions.TryFromJson(storedJson, out var restored) || restored is null)
{
    // Stored value is malformed, empty, whitespace, or the literal null
    return;
}

Console.WriteLine(restored.AuditingEnabled);  // True
```

Because `TryFromJson` returns `true` for the literal `null`, check `value` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **The name does not match the behavior:** The class does not extend `IServiceCollection` and does not touch DI registration. For registration helpers, see [ServiceCollectionExtensions](ServiceCollectionExtensions.md). The file imports `Microsoft.Extensions.DependencyInjection`, but the code does not use it, and the file compiles without that import.
*   **`TryFromJson` argument checks differ from the XML docs:** A null `json` throws `ArgumentNullException`, as documented. An empty string throws `ArgumentException`, not `ArgumentNullException`, because the code calls `ArgumentException.ThrowIfNullOrEmpty`. Callers that catch only `ArgumentNullException` will miss the empty-string case.
*   **`FromJson` returns `null` for blank input:** An empty or whitespace-only string returns `null` instead of throwing. Only a null argument throws.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON, so the method returns `true` and sets `value` to `null`. Check `value` before using it.
*   **Lenient reads:** Property names are matched without regard to case, and unknown properties are ignored. Malformed JSON still throws a `JsonException` from `FromJson` and returns `false` from `TryFromJson`.
*   **`ToJson` is visible on every type:** Because the receiver is `object?`, the method is offered for any value in the `RedisCachePatterns.Extensions` namespace. Types with their own `ToJson` extension method keep their overload, since the more specific one is chosen when both are in scope.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
