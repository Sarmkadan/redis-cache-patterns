# IdempotencyHelperJsonExtensions

> **Status: source removed.** `Utilities/IdempotencyHelperJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `IdempotencyHelperJsonExtensions` class is a static collection of extension methods that convert an `IdempotencyHelper` to JSON and back with System.Text.Json. The type lives in the `RedisCachePatterns.Utilities` namespace. Serialization uses web defaults with camelCase names, omits null properties, and ignores reference cycles.

`ToJson` is an extension method on `IdempotencyHelper`, so it is called on an instance. `FromJson` and `TryFromJson` take a JSON string and are called on the class. The methods do not change any state.

## API

### ToJson

```csharp
public static string ToJson(this IdempotencyHelper value, bool indented = false)
```

Serializes an `IdempotencyHelper` instance to a JSON string. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **value**: The idempotency helper to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the instance.
- **Throws**: `ArgumentNullException` when `value` is null.

### FromJson

```csharp
public static IdempotencyHelper? FromJson(string json)
```

Deserializes a JSON string to an `IdempotencyHelper`.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized instance, or `null` if the JSON is malformed, is whitespace, or is the literal `null`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty (`""`).

The null and empty checks run before deserialization. A `JsonException` is caught and turned into a `null` return. A whitespace-only string is not caught by the empty check, so it reaches the deserializer and returns `null`.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out IdempotencyHelper? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized instance when the method returns `true`. Set to `null` when the method returns `false`.
- **Returns**: `true` if the JSON was read without a `JsonException`, including the literal `null`; otherwise, `false`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty (`""`).

The method returns `true` with a `null` value for the literal `null`. It returns `false` for malformed JSON and for a whitespace-only string.

## Serialized format

`System.Text.Json` writes the public properties of the instance. `IdempotencyHelper` has no public properties. Its public surface is methods (`IsProcessed`, `MarkAsProcessed`, `GetResult`, `ExecuteIdempotentlyAsync`, `CleanupExpiredRecords`) and its records are held in private state. The same is true at `498581e^` and in the current tree.

As a result, `ToJson` writes an empty object:

```json
{}
```

The JSON does not carry the processed keys or stored results. A round trip through `ToJson` and `FromJson` returns a new instance with no recorded state.

## Usage

### Serializing an instance

```csharp
using RedisCachePatterns.Utilities;

IdempotencyHelper helper = ...; // an existing instance

string json = helper.ToJson();                   // compact
string pretty = helper.ToJson(indented: true);   // indented
```

### Reading JSON and handling bad input

```csharp
using RedisCachePatterns.Utilities;

if (!IdempotencyHelperJsonExtensions.TryFromJson(storedJson, out var restored) || restored is null)
{
    // Stored value is malformed, whitespace, or the literal null
    return;
}
```

Because `TryFromJson` returns `true` for the literal `null`, check `restored` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **Empty input throws, malformed input does not:** `FromJson` and `TryFromJson` throw `ArgumentException` for `""`, but return `null` or `false` for malformed JSON. Callers must handle both.
*   **Only `JsonException` is caught:** Other exceptions raised while deserializing, for example from the type's constructor, propagate to the caller.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON. Check `value` before using it.
*   **Whitespace is not treated as empty:** `ArgumentException.ThrowIfNullOrEmpty` is used, so `"   "` reaches the deserializer. `FromJson` returns `null` and `TryFromJson` returns `false`.
*   **The format carries no state:** Because `IdempotencyHelper` has no public properties, the JSON never contains the idempotency records. Do not use this JSON to move or back up idempotency state.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance with `JsonSerializerDefaults.Web`, `WriteIndented = false`, camelCase names, `DefaultIgnoreCondition = WhenWritingNull`, and `ReferenceHandler.IgnoreCycles`. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created.
