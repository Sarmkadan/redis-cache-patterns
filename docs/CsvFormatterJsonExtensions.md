# CsvFormatterJsonExtensions

> **Status: source removed.** `Formatters/CsvFormatterJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `CsvFormatterJsonExtensions` class is a static collection of extension methods that convert a `CsvFormatter` to and from JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Formatters` namespace. Serialization uses web defaults with camelCase names, and enum values are written as camelCase strings. The methods do not change the `CsvFormatter` instance they are called on.

## API

### ToJson

```csharp
public static string ToJson(this CsvFormatter value, bool indented = false)
```

Serializes a `CsvFormatter` to a JSON string. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **value**: The formatter instance to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the formatter.
- **Throws**: `ArgumentNullException` when `value` is null.

Only public readable properties are written. The delimiter is stored in a private field, so it is not part of the JSON.

### FromJson

```csharp
public static CsvFormatter? FromJson(string json)
```

Deserializes a JSON string to a `CsvFormatter`.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized formatter. `null` if `json` is only whitespace.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty. `JsonException` when the JSON is invalid or cannot be converted to a `CsvFormatter`.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out CsvFormatter? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized formatter when the method returns `true`. Set to `null` in every other case.
- **Returns**: `true` if the JSON was read without a `JsonException`; otherwise, `false`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty.

The method returns `false` without throwing when `json` is only whitespace. It returns `true` with a `null` value when `json` is the literal `null`.

## Serialized format

A formatter created with `new CsvFormatter()` serializes to:

```json
{"contentType":"text/csv"}
```

- `contentType` is the only public readable property of `CsvFormatter`. It is always `text/csv`.
- The delimiter passed to the constructor does not appear in the output.

## Usage

### Serializing a formatter

```csharp
using RedisCachePatterns.Formatters;

var formatter = new CsvFormatter(";");

string json = formatter.ToJson();               // compact
string pretty = formatter.ToJson(indented: true);
```

### Reading a formatter and handling bad input

```csharp
using RedisCachePatterns.Formatters;

if (!CsvFormatterJsonExtensions.TryFromJson(storedJson, out var restored) || restored is null)
{
    // Stored value is malformed, empty, or the literal null
    return;
}
```

Because `TryFromJson` returns `true` for the literal `null`, check `value` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`, together with 45 other generated `*JsonExtensions.cs` files. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **The delimiter is not round-tripped:** `ToJson` writes only `contentType`. A formatter restored with `FromJson` does not keep the delimiter it had before serialization.
*   **Deserialization is not verified:** `CsvFormatter` has no public parameterless constructor. Its only constructor takes `delimiter`, which does not match a settable public property. Reading the code, System.Text.Json is expected to fail when it creates the object, so `FromJson` and `TryFromJson` may not return a usable formatter for any input. This was not confirmed by running the code.
*   **`TryFromJson` throws for empty input:** The XML documentation says that a null or empty `json` throws. The code does the same: `ArgumentException.ThrowIfNullOrEmpty` runs before the whitespace check, so only whitespace returns `false`.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON, so the method returns `true` and sets `value` to `null`. Check `value` before using it.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
*   **Only `CsvFormatter` is covered:** The class has one set of methods for `CsvFormatter`. It does not handle other formatters, and it does not handle any lists of formatters.
