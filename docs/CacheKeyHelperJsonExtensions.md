# CacheKeyHelperJsonExtensions

> **Status: source removed.** `Utilities/CacheKeyHelperJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `CacheKeyHelperJsonExtensions` class is a static collection of methods that read and write a cache key configuration as JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Utilities` namespace. The configuration is a nested record, `CacheKeyHelperJsonExtensions.CacheKeyConfiguration`, that holds a separator and a wildcard. Serialization uses web defaults with camelCase names. The methods do not change any state.

Unlike the other `*JsonExtensions` classes in this repository, these methods are not extension methods. They take the separator and wildcard as arguments, so they do not read the values from `CacheKeyHelper`. The `Separator` and `Wildcard` constants in `CacheKeyHelper` are `private`, so nothing enforces that the two stay in sync.

## API

### ToJson

```csharp
public static string ToJson(string separator, string wildcard, bool indented = false)
```

Serializes a separator and a wildcard as a `CacheKeyConfiguration` JSON object. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **separator**: The separator used between key segments, such as `:`.
- **wildcard**: The wildcard used for pattern matching, such as `*`.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the configuration.
- **Throws**: `ArgumentNullException` when `separator` or `wildcard` is null.

Empty strings are accepted and written as they are. The method does not check that the values are valid key characters.

### FromJson

```csharp
public static CacheKeyConfiguration? FromJson(string? json)
```

Deserializes a JSON string to a `CacheKeyConfiguration`. Property names are matched without regard to case.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized configuration. `null` if `json` is `null` or empty (`""`), or if `json` is the literal `null`.
- **Throws**: `JsonException` when the JSON is malformed or cannot be converted to a `CacheKeyConfiguration`. A whitespace-only string is not empty, so it is passed to the deserializer and throws `JsonException`.

The method does not throw `ArgumentNullException` for a null `json`. It returns `null`. See the notes below.

### TryFromJson

```csharp
public static bool TryFromJson(string? json, out CacheKeyConfiguration? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized configuration when the method returns `true`. Set to `null` before any other check, so it is `null` whenever the method returns `false`.
- **Returns**: `true` if the input was null or empty, or if it was read without a `JsonException`; otherwise, `false`.

The method returns `true` with a `null` value when `json` is `null`, empty, or the literal `null`. It returns `false` for a whitespace-only string or for malformed JSON.

## Serialized format

A configuration with the separator `:` and the wildcard `*` serializes to:

```json
{"separator":":","wildcard":"*"}
```

- `separator` and `wildcard` are the two properties of the record. Both are written as strings in camelCase.
- The output has no other properties and no null values, because both properties are required strings.

## Usage

### Serializing the configuration

```csharp
using RedisCachePatterns.Utilities;

string json = CacheKeyHelperJsonExtensions.ToJson(":", "*");                  // compact
string pretty = CacheKeyHelperJsonExtensions.ToJson(":", "*", indented: true);
```

### Reading the configuration and handling bad input

```csharp
using RedisCachePatterns.Utilities;

CacheKeyHelperJsonExtensions.CacheKeyConfiguration? config =
    CacheKeyHelperJsonExtensions.FromJson(json);

if (!CacheKeyHelperJsonExtensions.TryFromJson(storedJson, out var restored) || restored is null)
{
    // Stored value is malformed, whitespace, or the literal null
    return;
}

Console.WriteLine(restored.Separator);  // :
```

Because `TryFromJson` returns `true` for `null`, empty, and the literal `null`, check `value` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **`FromJson` and `TryFromJson` do not throw for null:** The XML documentation of both methods says that a null `json` throws `ArgumentNullException`. The code does not do this. `FromJson` returns `null`, and `TryFromJson` returns `true` with a `null` value. Callers that expect the exception will not get it.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON, so the method returns `true` and sets `value` to `null`. Check `value` before using it.
*   **Whitespace is not treated as empty:** `string.IsNullOrEmpty` is used for the check, so `"   "` goes to the deserializer. `FromJson` throws `JsonException` for it, and `TryFromJson` returns `false`.
*   **Only the two strings are covered:** The configuration holds a separator and a wildcard. It does not hold any other `CacheKeyHelper` setting, and the methods do not validate the values.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
