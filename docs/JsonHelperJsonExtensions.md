# JsonHelperJsonExtensions

> **Status: source removed.** `Utilities/JsonHelperJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `JsonHelperJsonExtensions` class is a static collection of extension methods that convert a `JsonHelper` to JSON and back with System.Text.Json. The type lives in the `RedisCachePatterns.Utilities` namespace. Serialization uses the `JsonHelper` option sets with camelCase property names. Null properties are omitted, which follows from those option sets.

`ToJson` is an extension method on `JsonHelper`, so it is called on an instance. `FromJson` and `TryFromJson` are extension methods on `string`, so they are called on the JSON text (`json.FromJson()`). They can also be called statically as `JsonHelperJsonExtensions.FromJson(json)`. The methods do not change any state.

## API

### ToJson

```csharp
public static string ToJson(this JsonHelper value, bool indented = false)
```

Serializes a `JsonHelper` instance to a JSON string. When `indented` is `true`, the output uses `JsonHelper.IndentedOptions`. Otherwise it uses a camelCase copy of `JsonHelper.DefaultOptions`.

- **value**: The `JsonHelper` instance to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the instance.
- **Throws**: `ArgumentNullException` when `value` is null.

### FromJson

```csharp
public static JsonHelper? FromJson(this string json)
```

Deserializes a JSON string to a `JsonHelper`.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized instance, or `null` if the JSON is malformed, is whitespace, or is the literal `null`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty (`""`).

The null and empty checks run before deserialization. A `JsonException` is caught and turned into a `null` return. A whitespace-only string is not caught by the empty check, so it reaches the deserializer and returns `null`.

### TryFromJson

```csharp
public static bool TryFromJson(this string json, out JsonHelper? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized instance when the method returns `true`. Set to `null` when the method returns `false`.
- **Returns**: `true` if the JSON was read without a `JsonException`, including the literal `null`; otherwise, `false`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty (`""`).

The method returns `true` with a `null` value for the literal `null`. It returns `false` for malformed JSON and for a whitespace-only string.

## Serialized format

`System.Text.Json` writes the public instance properties of the object. `JsonHelper` has no public instance properties. Its public surface is static members (`DefaultOptions`, `IndentedOptions`, `Serialize<T>`, `Deserialize<T>`, `DeserializeSafe<T>`, `IsValidJson`, `GetValue`, `Merge`). Static members are not serialized. The same is true at `498581e^` and in the current tree.

As a result, `ToJson` writes an empty object, in both compact and indented form:

```json
{}
```

The JSON carries no state. A round trip through `ToJson` and `FromJson` returns a new, empty `JsonHelper`.

## Usage

### Serializing an instance

```csharp
using RedisCachePatterns.Utilities;

var helper = new JsonHelper();

string json = helper.ToJson();                   // compact: {}
string pretty = helper.ToJson(indented: true);   // indented
```

### Reading JSON and handling bad input

```csharp
using RedisCachePatterns.Utilities;

if (!storedJson.TryFromJson(out var restored) || restored is null)
{
    // Stored value is malformed, whitespace, or the literal null
    return;
}
```

Because `TryFromJson` returns `true` for the literal `null`, check `restored` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods. `Utilities/JsonHelper.cs` still exists and is the type these methods targeted, but its API is different. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **Empty input throws, malformed input does not:** `FromJson` and `TryFromJson` throw `ArgumentException` for `""`, but return `null` or `false` for malformed JSON. Callers must handle both.
*   **Only `JsonException` is caught:** Other exceptions raised while deserializing, for example from the type's constructor, propagate to the caller.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON. Check `value` before using it.
*   **Whitespace is not treated as empty:** `ArgumentException.ThrowIfNullOrEmpty` is used, so `"   "` reaches the deserializer. `FromJson` returns `null` and `TryFromJson` returns `false`.
*   **The format carries no state:** Because `JsonHelper` has no public instance properties, the JSON never contains any data. Do not use this JSON to move or back up state.
*   **Shared options:** The methods use a camelCase copy of `JsonHelper.DefaultOptions`, created once when the class is first used. `ToJson(indented: true)` uses `JsonHelper.IndentedOptions` instead. Neither instance is changed by these methods.
