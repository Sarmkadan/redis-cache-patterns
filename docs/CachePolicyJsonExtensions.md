# CachePolicyJsonExtensions

> **Status: source removed.** `Domain/CachePolicyJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `CachePolicyJsonExtensions` class is a static collection of extension methods that convert a `CachePolicy` to and from JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Domain` namespace. Serialization uses web defaults with camelCase names, and enum values are written as camelCase strings. The methods do not change the `CachePolicy` instance they are called on.

## API

### ToJson

```csharp
public static string ToJson(this CachePolicy value, bool indented = false)
```

Serializes a `CachePolicy` to a JSON string. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **value**: The cache policy to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the cache policy.
- **Throws**: `ArgumentNullException` when `value` is null.

Properties that are `null` (`UpdatedAt` and `Description`) are left out of the output. The other properties are always written, including `false` and `0` values.

### FromJson

```csharp
public static CachePolicy? FromJson(string json)
```

Deserializes a JSON string to a `CachePolicy`. Property names are matched without regard to case, and enum names are matched without regard to case as well.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized cache policy. `null` if `json` is empty or only whitespace, or if `json` is the literal `null`.
- **Throws**: `ArgumentNullException` when `json` is null. `JsonException` when the JSON is malformed or cannot be converted to a `CachePolicy`, for example when an enum name is unknown.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out CachePolicy? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized policy when the method returns `true`. Set to `null` in every other case.
- **Returns**: `true` if the JSON was read without a `JsonException`; otherwise, `false`.

The method returns `false` without throwing when `json` is null, empty, or only whitespace. It returns `true` with a `null` value when `json` is the literal `null`. The XML documentation of this method says that it throws `ArgumentNullException` for a null `json`. The code does not do this. See the notes below.

## Serialized format

A policy created with `new CachePolicy("product:*", TimeSpan.FromMinutes(90), CachePattern.WriteThrough)` serializes to:

```json
{"key":"product:*","defaultExpiration":"01:30:00","pattern":"writeThrough","useCompression":false,"maxSize":1048576,"isActive":true,"createdAt":"2026-10-25T00:47:15.1015052Z"}
```

- `defaultExpiration` is a `TimeSpan` and is written in the standard `[d.]hh:mm:ss` format.
- `pattern` is a `CachePattern` and is written as a camelCase name: `cacheAside`, `writeThrough`, `writeAround`, or `refreshAhead`.
- `createdAt` is written in ISO 8601 format.

## Usage

### Serializing a policy

```csharp
using RedisCachePatterns.Domain;

var policy = new CachePolicy("product:*", TimeSpan.FromMinutes(90), CachePattern.WriteThrough);

string json = policy.ToJson();               // compact
string pretty = policy.ToJson(indented: true);
```

### Reading a policy and handling bad input

```csharp
using RedisCachePatterns.Domain;

CachePolicy? policy = CachePolicyJsonExtensions.FromJson(json);

if (!CachePolicyJsonExtensions.TryFromJson(storedJson, out var restored) || restored is null)
{
    // Stored value is malformed, empty, or the literal null
    return;
}

Console.WriteLine(restored.Pattern);  // WriteThrough
```

Because `TryFromJson` returns `true` for the literal `null`, check `value` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **`TryFromJson` does not throw for null:** The XML documentation says that a null `json` throws `ArgumentNullException`. The code returns `false` instead, because `string.IsNullOrWhiteSpace` accepts null. Callers that rely on the exception will not get it. Callers that rely on `false` will get it. This was confirmed by running the code, not just by reading it.
*   **`TryFromJson` can return `true` with a null value:** The literal `null` is valid JSON, so the method returns `true` and sets `value` to `null`. Check `value` before using it.
*   **Enum and property names are lenient on read:** Enum names are matched without regard to case, and numeric enum values such as `1` are accepted. Property names are matched without regard to case. Unknown enum names are rejected with a `JsonException`.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
*   **Only `CachePolicy` is covered:** The class has one set of methods for `CachePolicy`. It does not handle other types, and it does not handle any lists of policies.
