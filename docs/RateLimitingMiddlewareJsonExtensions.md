# RateLimitingMiddlewareJsonExtensions

> **Status: source removed.** `Middleware/RateLimitingMiddlewareJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `RateLimitingMiddlewareJsonExtensions` class is a static collection of extension methods that convert a `RateLimitingMiddleware` to and from JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Middleware` namespace. Serialization uses web defaults with camelCase names. The methods do not change the `RateLimitingMiddleware` instance they are called on.

The methods are not useful in practice. `RateLimitingMiddleware` has no public properties, so every instance serializes to `{}`, and deserialization fails for every JSON object (see the notes below). The rate limit settings are not part of the JSON.

## API

### ToJson

```csharp
public static string ToJson(this RateLimitingMiddleware value, bool indented = false)
```

Serializes a `RateLimitingMiddleware` to a JSON string. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **value**: The middleware instance to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the middleware. Always `{}`.
- **Throws**: `ArgumentNullException` when `value` is null.

### FromJson

```csharp
public static RateLimitingMiddleware? FromJson(string json)
```

Deserializes a JSON string to a `RateLimitingMiddleware`.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized middleware instance, or `null` when `json` is the literal `null`.
- **Throws**: `ArgumentNullException` when `json` is null. `ArgumentException` when `json` is empty or only whitespace. `InvalidOperationException` when `json` is any other input, including malformed JSON and valid JSON objects such as `{}`.

The XML documentation says that invalid JSON returns `null`. The code does not do this. See the notes below.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out RateLimitingMiddleware? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized middleware instance when the method returns `true`. Set to `null` in every other case.
- **Returns**: `true` if the JSON was read without a `JsonException`; otherwise, `false`.
- **Throws**: `ArgumentNullException` when `json` is null.

Empty and whitespace-only input return `false` without throwing. The literal `null` returns `true` with `value` set to `null`. Any JSON object throws `InvalidOperationException`, because the `JsonException` catch does not match it. See the notes below.

## Serialized format

Every `RateLimitingMiddleware` serializes to:

```json
{}
```

- The class exposes no public properties, so no field is written. The policy and the request history are private fields, so they are not written either.
- The `indented` form is also `{}`.

## Usage

### Serializing a middleware instance

```csharp
using RedisCachePatterns.Middleware;

var middleware = new RateLimitingMiddleware(logger);

string json = middleware.ToJson();   // "{}"
```

### Reading a middleware instance

Do not rely on `FromJson` or `TryFromJson` to read a `RateLimitingMiddleware` from stored JSON. Any JSON object throws `InvalidOperationException`, and `TryFromJson` does not catch it.

```csharp
using RedisCachePatterns.Middleware;

// Throws InvalidOperationException for "{}" and for any other JSON object.
RateLimitingMiddleware? restored = RateLimitingMiddlewareJsonExtensions.FromJson("{}");
```

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`, together with 45 other generated `*JsonExtensions.cs` files. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **Deserialization always fails for objects:** `RateLimitingMiddleware` has only one constructor, which takes a required `ILogger<RateLimitingMiddleware>`. System.Text.Json cannot bind that parameter to any property or field, so it fails while preparing the type, before it reads the JSON. The error is `InvalidOperationException` ("Each parameter in the deserialization constructor ... must bind to an object property or field"). It is not a `JsonException`. This happens for valid input (`{}`) and for malformed input (`{bad`) alike.
*   **`FromJson` does not return `null` for bad JSON:** The XML documentation says that invalid JSON returns `null`. The code catches `JsonException` only, so `FromJson` throws for every object.
*   **`TryFromJson` does not return `false` for bad JSON:** The method catches `JsonException` only, so the `InvalidOperationException` from the previous note escapes it. In the probe, the method returned `false` only for empty or whitespace input.
*   **Empty input is handled differently:** `FromJson` throws `ArgumentException` for empty and whitespace input, because it checks `json.Trim()` first. `TryFromJson` does not check for empty input, so it returns `false` for both.
*   **The literal `null` is valid input:** `FromJson("null")` returns `null`. `TryFromJson("null")` returns `true` with `value` set to `null`. Check `value` before using it.
*   **The settings are not round-tripped:** Because `ToJson` writes `{}`, no rate limit policy or request history survives serialization. Any deserialization that does succeed would produce a new instance with default state, not a copy of the original.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
*   **Only `RateLimitingMiddleware` is covered:** The class has one set of methods for `RateLimitingMiddleware`. It does not handle `RateLimitPolicy`, and it does not handle lists of middleware instances.
*   **Verification:** The behavior above was checked by building the last version of this file (`498581e^`) together with the current `Middleware/RateLimitingMiddleware.cs` in a scratch project outside the repository, with a stub `ILogger<T>`. The serialization results and exception types were observed by running that project on .NET 10.
