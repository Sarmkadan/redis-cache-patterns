# OrderItemJsonExtensions

> **Status: source removed.** `Domain/OrderItemJsonExtensions.cs` was deleted from the repository in commit `498581e` ("fix: remove junk JsonExtensions files generated by engines"). This page describes the last version of the file (`498581e^`). It does not describe code that is in the current tree. Check the commit before relying on any of the behavior below.

The `OrderItemJsonExtensions` class is a static collection of extension methods that convert an `OrderItem` to and from JSON with System.Text.Json. The type lives in the `RedisCachePatterns.Domain` namespace. Serialization uses web defaults with camelCase names. The methods do not change the `OrderItem` instance they are called on.

## API

### ToJson

```csharp
public static string ToJson(this OrderItem value, bool indented = false)
```

Serializes an `OrderItem` to a JSON string. When `indented` is `true`, the output is formatted with line breaks and indentation. Otherwise the output is compact.

- **value**: The order item to serialize.
- **indented**: `true` to format the JSON for reading; `false` (default) for a compact single-line string.
- **Returns**: The JSON representation of the order item.
- **Throws**: `ArgumentNullException` when `value` is null.

The read-only `Subtotal` property is written to the output along with the stored state. See the notes below.

### FromJson

```csharp
public static OrderItem? FromJson(string json)
```

Deserializes a JSON string to an `OrderItem`. Property names are matched without regard to case.

- **json**: The JSON string to deserialize.
- **Returns**: The deserialized order item. `null` if `json` is `null`, empty, or whitespace, or if the input is the literal `null`.
- **Throws**: `JsonException` when `json` is not valid JSON or cannot be deserialized into an `OrderItem`.

Unlike the other methods in this class, `FromJson` does not throw `ArgumentNullException` for a null `json`. It returns `null`.

### TryFromJson

```csharp
public static bool TryFromJson(string json, out OrderItem? value)
```

Attempts to deserialize a JSON string. It catches `JsonException` and returns `false` instead of throwing.

- **json**: The JSON string to deserialize.
- **value**: Receives the deserialized order item when the method returns `true`. Set to `null` when the method returns `false`.
- **Returns**: `true` if the JSON was read without a `JsonException`; otherwise, `false`.
- **Throws**: Nothing from this method. A null, empty, or whitespace `json` returns `false`.

The method returns `true` with a `null` value when `json` is the literal `null`. The XML documentation says that a null `json` throws `ArgumentNullException`. The code does not do this. See the notes below.

## Serialized format

An order item created with the following values and serialized in compact form:

```csharp
var item = new OrderItem
{
    ProductId = 1,
    Quantity = 2,
    UnitPrice = 19.99m,
    DiscountPercent = 10,
    AddedAt = new DateTime(2026, 10, 25, 12, 0, 0, DateTimeKind.Utc)
};
```

produces this output:

```json
{"id":0,"orderId":0,"productId":1,"quantity":2,"unitPrice":19.99,"discountPercent":10,"addedAt":"2026-10-25T12:00:00Z","subtotal":35.982}
```

- `id`, `orderId`, `productId`, and `quantity` are integers and are always written.
- `unitPrice` and `discountPercent` are `decimal` values and are written as JSON numbers.
- `addedAt` is a `DateTime` written in ISO 8601 format. A UTC value ends with `Z`.
- `product` is omitted when the `Product` property is `null`, because the options use `WhenWritingNull`. When it is set, the product is written as a nested object.
- `subtotal` is computed from `UnitPrice`, `Quantity`, and `DiscountPercent`. It is written as a snapshot and is ignored when the JSON is read.
- `GetDiscountAmount()` is a method, not a property, so it does not appear in the output.

## Usage

### Serializing an order item

```csharp
using RedisCachePatterns.Domain;

var item = new OrderItem { ProductId = 1, Quantity = 2, UnitPrice = 19.99m, DiscountPercent = 10 };

string json = item.ToJson();                // compact
string pretty = item.ToJson(indented: true);
```

### Reading an order item and handling bad input

```csharp
using RedisCachePatterns.Domain;

if (!OrderItemJsonExtensions.TryFromJson(storedJson, out var restored) || restored is null)
{
    // Stored value is malformed, empty, whitespace-only, null, or the literal null
    return;
}

Console.WriteLine(restored.ProductId);  // 1
```

Because `TryFromJson` returns `true` for the literal `null`, check `value` for `null` as well as the return value.

## Notes

*   **The source file no longer exists:** The code this page describes was removed in `498581e`. Nothing in the current tree calls these methods, and the file name is not in use. Restore the file from `498581e^` before depending on this API, or delete this page.
*   **`TryFromJson` XML documentation does not match the code:** The `<exception>` tag says a null `json` throws `ArgumentNullException`. The code checks `string.IsNullOrWhiteSpace(json)` and returns `false`. Callers that rely on the exception will not get it.
*   **`FromJson` does not throw for null, empty, or whitespace input:** These inputs return `null`. Only invalid JSON throws, as `JsonException`.
*   **Computed fields are written as snapshots:** `subtotal` is computed when `ToJson` runs and is ignored on read. Do not store it as the source of truth for the price. Use `UnitPrice`, `Quantity`, and `DiscountPercent` instead.
*   **Round-trip keeps the stored state:** `id`, `orderId`, `productId`, `quantity`, `unitPrice`, `discountPercent`, and `addedAt` are restored. `product` is restored only if it was written.
*   **Cycles through `Product` are written as `null`:** `Product.OrderItems` can point back to the item being serialized. The options use `ReferenceHandler.IgnoreCycles`, so that back-reference is written as `null`. The restored `Product.OrderItems` list contains a `null` entry instead of the original item.
*   **Null checks in `ToJson`:** `ToJson` throws `ArgumentNullException` for a null `value`. `ArgumentNullException` is a subclass of `ArgumentException`, so a `catch (ArgumentException)` handles it too.
*   **Shared options:** The methods use one shared `JsonSerializerOptions` instance. `ToJson(indented: true)` creates a copy of it for each call. The shared instance is not changed after it is created, so the methods are safe to call from several threads.
*   **Time zone in `addedAt`:** A `DateTime` with `DateTimeKind.Local` is written with a UTC offset, not `Z`. `OrderItem.AddedAt` defaults to `DateTime.UtcNow`, so the default output ends in `Z`.
*   **Only `OrderItem` is covered:** The class has one set of methods for `OrderItem`. It does not handle `List<OrderItem>` or `Order` objects.
